# Project Freedom

Project Freedom is a personal financial independence dashboard.

The aim is simple:

Help people understand when work becomes optional.

This project combines:

- Pension forecasting

- Net worth tracking

- Investment growth

- Property equity

- Retirement planning

- Financial independence metrics

## Vision

Project Freedom helps people understand their financial future by transforming pensions, investments, property and savings into one simple measure of progress towards financial independence.
